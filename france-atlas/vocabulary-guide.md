## 4. Felsefe, Münazara ve Retorik Bağlaçları

Fransızca akademik ve diplomatik müzakerelerde argüman kurarken kullanılan temel geçiş kalıpları:

| Bağlaç / Kalıp | Türkçe Anlamı | Kullanım Amacı |
| :--- | :--- | :--- |
| **Tout d'abord / Premièrement** | Her şeyden önce / İlk olarak | Giriş ve ilk argümanı sunma |
| **En ce qui concerne / Quant à...** | ... konusuna gelince / ... hususunda | Konu başlığını belirleme |
| **Par conséquent / Ainsi** | Sonuç olarak / Dolayısıyla | Mantıksal çıkarım yapma |
| **Néanmoins / Cependant** | Yine de / Bununla birlikte | Karşı argüman veya kısıtlama getirme |
| **En revanche / Par contre** | Buna karşılık / Öte yandan | Zıtlıkları vurgulama |
| **Il convient de souligner que...** | ... vurgulamakta yarar vardır ki | Önemli bir noktanın altını çizme |
| **À mon humble avis / Selon nous** | Naçizane görüşüme göre / Bize göre | Fikir beyan etme |
| **Dans quelle mesure peut-on dire que...** | Hangi ölçüde söylenebilir ki... | Münazara sorusu sorma |
| **En conclusion / Pour récapituler** | Sonuç olarak / Özetlemek gerekirse | Kapanış ve sentez |

## 5. Gastronomi, Sofra Adabı ve Restoran İletişimi

| Fransızca İfade | Türkçe Karşılığı | İpucu & Görgü Kuralı |
| :--- | :--- | :--- |
| **Une table pour deux personnes, s'il vous plaît.** | İki kişilik bir masa lütfen. | Girişte garsonun yönlendirmesini bekleyiniz. |
| **La carte / Le menu, s'il vous plaît.** | Menüyü alabilir miyim lütfen? | *Menu* genellikle fiks fiyatlı set menüyü ifade eder. |
| **Une carafe d'eau (fraîche)** | Bir sürahi musluk suyu (ücretsiz) | Fransa'da restoranlarda sürahi su ücretsiz verilir. |
| **Je suis végétarien(ne) / végétalien(ne).** | Vejetaryenim / Veganım. | Diyet tercihinizi baştan belirtiniz. |
| **Je ne mange pas de porc.** | Domuz eti yemiyorum. | İçerik sorgularken kullanılır. |
| **Sans gluten / Sans lactose** | Glütensiz / Laktozsuz | Alerjen uyarıları. |
| **C'était délicieux, mes compliments au chef !** | Çok lezzetliydi, şefe tebriklerimi iletiniz! | Beğeni ifadesi. |
| **L'addition, s'il vous plaît.** | Hesap lütfen. | Yemeğin sonunda hesabı isteme. |
| **Puis-je payer par carte bancaire (sans contact) ?** | Kredi kartıyla (temassız) ödeyebilir miyim? | Ödeme yöntemi. |
| **Gardez la monnaie.** | Üstü kalsın (Bahşiş / *Pourboire*). | Servis ücreti faturaya dahildir, bahşiş isteğe bağlıdır. |
